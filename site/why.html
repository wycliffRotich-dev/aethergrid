AI workloads that finish, even when machines don’t.

AI jobs run for a long time on expensive machines, and machines fail. AetherGrid makes the system responsible for those failures, so your team spends its time on the work and not on rescuing it.

See it running

Pay for compute that is working, not waiting

Jobs are matched to nodes on CPU, memory and VRAM together, and when a job finishes, times out, is cancelled or loses its owner, its command is stopped along with anything it left running.

Best-fit scheduling (ADR 0043)Kill leftovers (ADR 0079)Supervisor ends (ADR 0083)

Sleep through the night when a machine fails

Every job has one owner, held through a renewable lease. If the owner disappears, reconciliation returns the job to a healthy worker and a stale worker cannot overwrite the result. Nobody has to be paged for the routine case.

Lease ownership (ADR 0005)Fenced outcomes (ADR 0036)Reconciliation (ADR 0007)

Answer “what happened?” in seconds

A dashboard shows nodes, jobs, each job’s event history and a live cluster feed. Requests and background loops write structured logs and errors are tracked, so your operators see what happened and why.

Event history (ADR 0008)Structured logs (ADR 0022)Error tracking (ADR 0023)

One platform, many customers, no shared data

Tenant isolation is enforced in the application and in the database, and the tenant comes from the credential, never from the request. Teams and customers share the cluster and never see each other.

Isolate by tenant (ADR 0064)Tenant-scoped jobs (ADR 0068)Tenant-scoped events (ADR 0074)

Upgrade with confidence

Schema changes ship as versioned migrations. Each release is rehearsed against a database from the release before it, so an upgrade is something you have already watched work.

Versioned migrations (ADR 0071)Upgrade rehearsal (ADR 0085)Schema comparison (ADR 0087)

Verify everything yourself

Open source under the MIT licence and started with Docker Compose. Every route needs an API key, the architecture layers are enforced by a test, and the reasoning behind each design choice is public.
